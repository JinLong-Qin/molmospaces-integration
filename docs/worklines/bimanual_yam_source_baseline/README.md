# Completed Custom-Scene Bimanual YAM Source Baseline

## Purpose

This completed workline preserved an earlier custom tabletop/box bimanual YAM source-demo baseline. It is useful because it showed a controlled custom-scene source-demo package could be captured, replayed, and QA-checked.

It is not the same as the current official iTHOR bimanual YAM workline.

## Public code and artifacts

The full runtime package included custom-scene capture/replay/QA scripts plus HDF5 and videos. In this public repository, the raw package is represented by an inventory rather than by committing the large runtime files.

Inventory: [`results/workline_index/bimanual_yam_source_baseline.md`](../../../results/workline_index/bimanual_yam_source_baseline.md)

## Reproducing or publishing the full package

To reproduce this line from a fresh clone, use the current bimanual YAM utilities in [`src/bimanual_yam/`](../../../src/bimanual_yam/) as the maintained entrypoints. The original custom-scene runtime package is indexed for provenance; if the exact HDF5/videos need to be public, publish them as release assets, Git LFS objects, or an external artifact bundle.
